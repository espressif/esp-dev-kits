ESP32-S31-Korvo-1
=================

:link_to_translation:`en:[English]`

ESP32-S31-Korvo-1 是一款面向智能音频与人机交互 (HMI) 应用的多媒体开发板，搭载 ESP32-S31-WROOM-3 模组，配备双麦克风阵列、扬声器输出、microSD 卡槽和板载 DVP 摄像头，支持语音识别与语音唤醒，并配套 4.3 英寸 LCD 子板 (ESP32-S3-LCD-EV-Board-SUB3)。本文档介绍 V1.1 版本。
