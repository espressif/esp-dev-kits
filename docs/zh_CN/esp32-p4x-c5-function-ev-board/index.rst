==============================
ESP32-P4X-C5-Function-EV-Board
==============================

:link_to_translation:`en:[English]`

ESP32-P4X-C5-Function-EV-Board 是一款基于 ESP32-P4 芯片的多媒体开发板。ESP32-P4 搭载双核 RISC-V 处理器，支持最大 32 MB PSRAM。此外，ESP32-P4 支持 USB 2.0 标准，MIPI-CSI/DSI，H264 Encoder 等多种外设。此开发板搭载 ESP32-C5-MINI-1 模组，支持 2.4 GHz & 5 GHz 双频 Wi-Fi 6 及 Bluetooth 5 (LE)，用于 Wi-Fi 和蓝牙通信。凭借上述特性，该开发板是开发低成本、高性能、低功耗联网音视频产品的理想选择。
